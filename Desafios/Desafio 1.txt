Objetivo

Construir sua VM para o treinamento, instalar dependências e colocar o projeto da BIA para rodar na sua máquina persistindo os dados localmente + conexão ao banco do DBeaver com o banco da BIA rodando com Docker. Com o setup concluído, baixei um projeto em Node.js com React e o coloquei para rodar localmente via Docker, tanto a parte web quanto o banco relacional PostgreSQL usando o RDS.

Etapa extra: Criar uma instância EC2 na AWS com Linux e subir o projeto local para AWS.

*Security group é usado para liberar a máquina (BIA-DEV) para está acessível na porta 3001 (são as regras de entrada), além dessas regras precisa associar uma autorização (role-acesso-ssm), onde vamos dizer o objetivo dessa role, no nosso caso é da autorização para a minha instância consiga se comunicar com outros serviços da AWS, para isso preciso associar uma role e nessa role vamos colocar as poles que são as autorizações que ela vai ter, sem isso ela não consegue conectar com os serviços da AWS.
